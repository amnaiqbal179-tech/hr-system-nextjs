# 🏢 HR Management System

An enterprise-grade **Human Resource Management System (HRMS)** built with Next.js, designed to streamline company operations, department management, employee tracking, and role-based access control.

---

## 🚀 Features

* **🔐 Role-Based Access Control (RBAC):** Secure authentication and authorization for Admins, HR Managers, and Employees.
* **📊 Comprehensive Admin Dashboard:** Real-time analytics, company-wide metrics, and centralized oversight.
* **👥 HR & Employee Management:** Easily onboard, update, and manage HR personnel and staff members.
* **🏢 Company & Department Directory:** Organize corporate structures, departments, and designations seamlessly.
* **⚡ Modern & Responsive UI:** Crafted with Tailwind CSS and Next.js App Router for high performance.
* **🔒 Secure Session Handling:** HttpOnly cookies and protected middleware routes to ensure enterprise security.

---

## 🛠️ Tech Stack

* **Framework:** [Next.js](https://nextjs.org/) (App Router, Turbopack)
* **Language:** [TypeScript](https://www.typescriptlang.org/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Database & ORM:** [Prisma ORM](https://www.prisma.io/) with PostgreSQL
* **Authentication:** Custom JWT-based cookie authentication
